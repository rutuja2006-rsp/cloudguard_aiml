# CloudBudget Guard

CloudBudget Guard is a cloud cost monitoring and analysis dashboard built using Python and Streamlit.

## Features
- Cloud Cost Dashboard
- Cost Forecasting
- Anomaly Detection

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Plotly
- Scikit-learn

## Run Locally
Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
